# FlashGrid Connect

A modern connection and collaboration-focused web application built with React and TypeScript.

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting started

```bash
git clone https://github.com/madhuarigela/flashgrid-connect.git
cd flashgrid-connect
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project focus

The repository contains the frontend application and configuration for a responsive connection-focused web experience.
